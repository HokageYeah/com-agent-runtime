# Task 10.5 对账调度接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在既有数据库租约保护的对账进程中执行回忆录删除补偿维护，并在安全报告中返回聚合计数。

**Architecture:** `ReconcilerRunner` 在每轮通用对账完成后、仍持有同一 lease/fencing token 时调用可注入的维护执行器。删除补偿服务在每项外部投递、确认和 GC 前检查租约；报告只包含计数与中止标识，绝不携带日记、播放文档或上游响应。

**Tech Stack:** Python 3.12、SQLAlchemy、pytest。

## Global Constraints

- 不记录日记正文、prompt、完整播放文档或上游 HTTP 响应。
- 网络副作用复用既有稳定幂等键，不新建消息队列。
- 工作区已有未提交改动；不执行 reset、checkout、提交或改写其他改动。
