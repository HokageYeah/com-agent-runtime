# Task 6.75 孤儿 Held Run 补偿 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 当 Runtime 已接受 held create、但业务侧尚未来得及绑定 RunRef 时，使用原 create 幂等键恢复同一 Run，或在归档失效时安全取消该孤儿 Run。

**Architecture:** 复用 `MemoryRuntimeLaunchEvent` 的 `run_id/create idempotency key` 与 Runtime 的 GET/cancel API；补偿不创建第二个 Run。若 archive 删除、generation 变化或 active run 被替换，取消 Runtime held Run 并将本地事件收敛为 delivered 的安全审计状态。

**Tech Stack:** Python、SQLAlchemy、httpx、pytest。

## Global Constraints

- 不新增 outbox、队列或业务表；复用既有 RunRef、IdempotencyService、HMAC。
- 日志与事件只记录 run/archive/event ID、epoch、标准错误码，禁止正文、Prompt、响应体。
- 保留共享脏工作区，不执行 reset、checkout、自动提交。
