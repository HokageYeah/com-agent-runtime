# Task 7 工具写入与 Task 8 路由安全 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` task-by-task.

**Goal:** 在有效 lease 下安全落工具结果，并拒绝不安全 Model/connector endpoint。

**Architecture:** 复用 `AgentState.apply_tool_output`、`LeaseService.can_write`、既有 ToolGateway 和 ModelRoute；使用 Python 标准库 `ipaddress/socket` 进行 fail-closed 预检，不新增 transport、DNS 缓存或状态机。

**Global Constraints:** 不记录正文/prompt/secret；不重放写工具；不新增依赖、后台线程或动态 endpoint；共享脏工作区不提交/reset。
