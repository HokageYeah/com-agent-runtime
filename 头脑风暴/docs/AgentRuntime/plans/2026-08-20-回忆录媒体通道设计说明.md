# 回忆录媒体通道设计说明（M6 / Phase D）

## 目标

为 MemoirAgent 生成的回忆录作品补齐图片媒体通道：场景规划后、发布前，按场景生成配图（无照片走文生图、有已共享日记照片且门禁开启走图生图），经阿里云 OSS 公共客户端上传，URL 随 `memory.publish_playback_document` 原子发布进业务侧 `media_manifest` 列。本文是 2026-08-20 设计增补，设计批次未写实现代码；**同日 D2 已按本文实现并经测试验证**（任务勾选见下），执行入口以情侣日记总控计划 M6（D1–D5）为准，本文承担 Runtime 侧 D2 的设计事实源。

## 已有基础与范围

已预留的骨架（零契约变更即可复用）：

- `image` Scene 与 `focus_image` 动作词表三端冻结；evaluator `_CAPABILITY_ACTIONS` 门控已按能力放行；
- workflow 尾部 `enqueue_media_tasks` 节点已存在（当前确定性跳过 `CAPABILITY_DISABLED`）、`state.media_tasks` 字段已预留；
- 业务表 `memory_playback_documents.media_manifest` 列已存在，Runtime/业务公开投影/前端 adapter 各层当前强制清空该字段（四处，M6 逐层解禁）；
- `app/utils/aliyun/oss_client.py` 公共客户端已具备文件上传与预签名能力，配置键已进 `app/core/config.py`（见 `ENV_CONFIG.md` §9.3）。

不在本块范围：TTS/音乐/视频生成（Phase E，条目 schema 已为其预留 `audio/video` kind）；S3 私有媒体代理通道（§9.1/9.2，服务对象是用户私密媒体，与本文公共读生成图通道互不混用）；前端渲染（D4，属情侣日记仓）。

## 方案选择

采用“同一节点单通道分支 + 一次冻结条目 schema”的方案：

1. **生成时机**：`generate_scenes` 之后、`publish` 之前同步并行执行，3–8 张并发、单张超时上限受 Worker 90s 租约约束（租约只在节点间心跳续期，单节点内不续）。不引入异步二段 revision——图片永不阻塞发布。
2. **单通道分支**：在既有 `enqueue_media_tasks` 节点槽位实装发布前同步生成（节点是否更名由实现的最小改动决定，不强求改名）——素材快照含共享日记照片引用且隐私门禁开 → 图生图（SeedEdit 指令编辑，结果保留原图内容要素）；否则文生图。是否含照片只影响图片输入，不影响场景规划与文案。
3. **降级阶梯**：单张失败/超时 → 该 Scene 降级文本卡（manifest 不含该条目）；全部失败 → 发布纯文字 revision（即现状）。任何图片异常都不产生重试节点、不回滚已生成文案。
4. **存储**：OSS 上传至 `memoir/images` 前缀（`memoir/videos`、`memoir/audios` 为 Phase E 预留）；object_key = 前缀 + 不可猜测 UUID；桶保持私有、**对象级公共读 ACL**；落库与下发用公共读 URL，预签名 URL 有时效不落库。
5. **兼容**：播放文档 `schema_version` 维持 `'1.0.0'` 不升版；老小程序包精确匹配失败时按既有降级路径渲染文本卡。

## 火山引擎接入事实（文档调研，未实测）

- 火山视觉智能 3.0 使用两段式异步接口：先以 `Action=CVSync2AsyncSubmitTask&Version=2022-08-31` 提交任务并取得 `task_id`，再以 `Action=CVSync2AsyncGetResult&Version=2022-08-31` 查询 `in_queue/generating/done` 状态；两次请求都按各自 canonical query 重新计算 AK/SK HMAC-SHA256 签名；
- 文生图固定 `req_key: high_aes_general_v30l_zt2i`，图生图固定 `req_key: seededit_v3.0`；图生图输入只传一个 `binary_data_base64`。查询接口不传可选 `req_json.return_url`，直接读取 `binary_data_base64`，避免临时 URL 下载与外泄面；
- 按张计费 → ModelUsage 需补按张计量字段（当前按 token），租户配额同步按张限。

## 安全与隐私边界

- **照片出域门禁默认关闭**：图生图输入只允许 `shared_to_partner=true` 的日记照片进入素材快照（业务端 D3 投影控制，Runtime 收不到即走文生图）；且仅允许 `data_residency=public` 的模型路由承载图像调用。开启需产品显式确认，配置独立开关。
- **出域内容最小化**：图像 prompt 只含场景摘要与风格指令，不含来源 ID、账号标识与完整正文；prompt、图片字节、临时 URL 不进入日志、trace、checkpoint、callback、Artifact 或测试输出。
- **计量与配额**：按张计费进 ModelUsage 结算；单作品张数受 Scene 上限（≤16）与并发上限约束。
- **URL 边界**：公共读 URL 只写入结构化白名单字段（manifest 条目与 image payload）；scene `body/title` 禁 URL 的既有防护不变。
