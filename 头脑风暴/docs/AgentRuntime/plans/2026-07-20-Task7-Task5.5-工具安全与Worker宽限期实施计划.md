# Task 7 工具安全与 Task 5.5 Worker 宽限期 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 ToolGateway、MemoirNodeRunner 与 WorkflowExecutor 在同一 draining/lease 安全边界停止新副作用、限制在途同步调用，并保留原审计键恢复不确定写操作。

**Architecture:** 复用现有 `is_draining` 注入、`LeaseService`、`ToolCallAuditService` 与 `AgentState.apply_tool_output`，仅在 ToolGateway 增加受控调用 guard 和 deadline timeout 截断。Worker 仍只在 Executor 返回的安全节点边界释放 lease；不创建后台线程、第二套状态机、HTTP 重试器或 DNS 缓存。

**Tech Stack:** Python、httpx、Pydantic、SQLAlchemy、pytest、现有 HMAC/ToolCallAudit/LeaseService。

## Global Constraints

- 不执行或新增动态 Agent 工具选择；Package 不能指定 URL、connector、身份、lease、generation 或 timeout。
- 日志、Artifact、checkpoint、ToolCall 审计不记录日记正文、prompt、完整播放文档或工具原始输出。
- 写工具不盲重试；未知结果仅按原 logical operation key、idempotency key、request digest 查询。
- 不新增后台 heartbeat 线程；长调用必须受同步 timeout 限制并在返回后进入现有 heartbeat/can_write 边界。
- 复用共享脏工作区改动，不 reset/checkout/自动提交。

```python
class ToolGateway:
    def __init__(..., *, is_draining: Callable[[], bool] = lambda: False) -> None:
        self._is_draining = is_draining

    def _call(..., allow_during_draining: bool = False) -> dict[str, Any]:
        if self._is_draining() and not allow_during_draining:
            logging.info("工具调用在发送前中止 tool=%s code=%s", tool_name, "TOOL_CALL_DRAINING")
            raise ValueError("TOOL_CALL_DRAINING")
```

```python
def repair_json_once(value: object) -> object | None:
    if not isinstance(value, str):
        return None
    candidate = value.removeprefix("```json").removesuffix("```").strip()
    try:
        return json.loads(candidate)
    except json.JSONDecodeError:
        return None
```

摘要只返回排序后的键名、容器大小和布尔敏感标识；不增加 LangChain 依赖或动态包装。`AgentState` 继续作为唯一 Tool 输出写入者，Native Tool 不直接修改 AgentState。

```python
def _effective_timeout(self, fixed_timeout: float) -> float:
    deadline = self._deadline_at()
    if deadline is None:
        return fixed_timeout
    remaining = (deadline - datetime.now(UTC)).total_seconds()
    if remaining <= 0:
        raise ValueError("TOOL_CALL_DEADLINE_EXPIRED")
    return min(fixed_timeout, remaining)
```

只允许 Worker 从已认领 `AgentRun` 与 `LeaseContext` 构造 deadline 回调；Executor 保持已有“节点返回后 heartbeat + can_write + checkpoint + draining result”顺序。ModelGateway 保持已有 call guard；补充回归验证其 Provider timeout 不超过可信 run deadline。不得用定时线程续租或在 drain 后启动下一节点。
