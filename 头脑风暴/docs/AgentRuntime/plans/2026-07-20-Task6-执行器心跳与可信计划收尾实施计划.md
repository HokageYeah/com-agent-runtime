# Task 6 执行器心跳与可信计划收尾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 WorkflowExecutor 只执行 Package 冻结的静态计划，在每个节点安全边界续约 lease，并在 fencing/privacy/authorization/cancel 失效时停止写入。

**Architecture:** AgentPackageService 已用 AST 只读解析 `WORKFLOW_NODES`，StaticPlanner 将注册 definition 中的冻结节点持久化到 AgentPlan；不再执行 Package Python。LeaseService 继续是唯一所有权来源，heartbeat 只刷新同一 LeaseContext 的到期时间；Executor 在节点前、节点返回后及 Artifact/checkpoint 前复用 `can_write`。

**Tech Stack:** Python、SQLAlchemy、Pydantic、pytest、现有 AgentPackageService、StaticPlanner、LeaseService、WorkflowExecutor。

## Global Constraints

- 禁止执行 `workflow.graph.py`，只接受 AgentPackageService 的 AST 字面量解析结果。
- 不新增第二套 workflow engine、heartbeat 线程、lease 表或 worker 状态机。
- 日记正文、Prompt、完整播放文档不得进入日志、Artifact、checkpoint 安全摘要或 callback。
- 共享脏工作区不得 reset/checkout/自动提交。
