# Task 6.75 Runtime 适配器实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让回忆录归档的 `MemoryRuntimeLaunchEvent` 在不阻塞 revision 0 baseline 的前提下，安全完成 Runtime readiness/capabilities 校验、held create/start 与 600 秒补偿。

**Architecture:** 使用现有 `MemoryRuntimeLaunchEvent` 作为唯一业务侧投递事实，HTTP adapter 仅实现其已有的 `MemoryRuntimeGateway` 窄接口。能力缓存为进程内、短 TTL 的安全摘要；每次缺失/过期或 Runtime 摘要变化时重新校验。Runtime 网络调用永不处于解绑数据库事务中，失败只让 outbox 保持 pending。

**Tech Stack:** Python 3.13、FastAPI、SQLAlchemy 2、httpx、Pydantic、pytest。

## Global Constraints

- 不新增消息队列、缓存依赖或第二套 outbox；复用 `MemoryRuntimeLaunchEvent`。
- Runtime 请求使用现有 HMAC canonical 格式与 `Idempotency-Key`；日志、event、RunRef 不保存密钥、日记正文、Prompt、快照正文或完整播放文档。
- 真实情侣日记业务表只读；不对其执行 DDL。Runtime 自有迁移仅纳入仓库，真实库迁移链统一前不得执行。
- 保留共享脏工作区，禁止 reset、checkout、自动提交。
- `pending_start_timeout_seconds` 固定为 600；超时只复用已冻结 create/start 键。

### Task 2: 实现最小 capability cache 与兼容性判定

**Files:**
- Create: `app/services/memory_runtime_capability_cache.py`
- Test: `tests/test_memory_runtime_capabilities.py`

**Consumes:** read-only Runtime readiness/capabilities JSON。

**Produces:** `MemoryRuntimeCapabilityCache.get_or_refresh(fetcher) -> RuntimeCapabilitySnapshot`，拒绝 draining、Contract major 不匹配、缺失 `memoir_agent@1.0.0`、缺失 policy 或 `workflow_agent=false`。

- [✅] 缓存命中时由 Adapter 以 HMAC 调用 capabilities 进行无敏感摘要探测；contract/package/agent/policy/workflow 任一摘要变化即丢弃 TTL 缓存，并重新执行 readiness + capabilities 完整握手。缺少 `package_digest` 保守拒绝，不再使用固定占位摘要。

```python
assert cache.get_or_refresh(fetch) is first
assert fetch.call_count == 1
```

另加 Contract `2.x`、缺少 `emotional_writing`、`workflow_agent=False` 时抛出 `MEMORY_RUNTIME_CAPABILITY_INCOMPATIBLE` 的断言。

- [ ] **Step 2: 运行失败测试。**

Run: `poetry run pytest -q tests/test_memory_runtime_capabilities.py`

Expected: FAIL，模块不存在。

- [ ] **Step 3: 实现 dataclass 快照与单槽缓存。**

```python
@dataclass(frozen=True)
class RuntimeCapabilitySnapshot:
    contract_version: str
    package_digest: str
    expires_at: datetime

def get_or_refresh(self, fetcher: Callable[[], RuntimeCapabilitySnapshot]) -> RuntimeCapabilitySnapshot:
    if self._snapshot is not None and self._clock() < self._snapshot.expires_at:
        return self._snapshot
    self._snapshot = fetcher()
    return self._snapshot
```

快照只存版本、agent/policy 集合、能力开关与过期时间；不存 URL、密钥、provider endpoint 或配额。
