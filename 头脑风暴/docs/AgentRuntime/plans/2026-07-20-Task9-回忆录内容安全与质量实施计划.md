# Task 9 回忆录内容安全与质量 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 MemoirAgent 的冻结快照转为最小语义脱敏素材，并在发布前保证 Scene 数量、文案长度、情绪安全和媒体关闭契约。

**Architecture:** `sanitize_materials` 作为静态 deterministic 节点紧接 `load_snapshot`，写入既有 `AgentState.sanitized_material`；高光与模型请求只从其安全 `source_refs` 读取。Scene/Action 约束继续收敛在 `MemoirNodeRunner` 的既有 schema 与 `safety_review`，不新增存储、动态工作流或媒体队列。

**Tech Stack:** Python、Pydantic、pytest、现有 MemoirNodeRunner、AgentState、ContextManager、ToolGateway。

## Global Constraints

- 不记录日记正文、赌局完整内容、prompt、工具原始输出或敏感命中原文。
- 敏感素材仅保留 `source_ref/type/sensitive`，不得提供文本给模型或 Artifact/checkpoint 摘要。
- 不新增 LangChain、媒体任务、数据库表、动态工具选择或后台线程。
- 保留共享脏工作区改动；不 reset/checkout/自动提交。

### Task 2: 高光输入、Scene 数量和安全审核约束

**Files:**
- Modify: `app/agents/memoir_agent/runner.py`
- Test: `tests/test_memoir_snapshot_runner.py`

**Interfaces:**
- Consumes: `sanitized_material.materials`、既有 StructuredOutputParser、Scene/Action 状态。
- Produces: 高光只使用非敏感 `source_ref`；`generate_scenes` 输出或 fallback 为 3～8 Scene；`safety_review` 只接受 3～16 Scene、`body` 至多 80 字、无禁用情绪词的文档。

- [✅] **Step 1: 写失败测试**

```python
def test_highlights_ignore_sensitive_material_reference() -> None:
    state = AgentState(sanitized_material={"materials": [{"source_ref": "diary:d1", "type": "diary", "sensitive": True}]})
    MemoirNodeRunner(object()).run_node({"node_id": "extract_highlights"}, _run(), state)
    assert state.highlights == {"source_refs": [], "mode": "template"}


def test_safety_review_replaces_overlong_or_too_many_scenes() -> None:
    state = AgentState(scenes=[{"scene_id": f"s{i}", "scene_type": "summary", "source_refs": [], "body": "x" * 81} for i in range(17)], actions=[])
    MemoirNodeRunner(object()).run_node({"node_id": "safety_review"}, _run(), state)
    assert len(state.playback_document["scenes"]) == 3
```

- [✅] **Step 2: 运行红灯测试**

Run: `poetry run pytest -q tests/test_memoir_snapshot_runner.py tests/test_memoir_model_gateway.py -k 'sensitive_material or overlong or too_many'`

Expected: FAIL，因为高光仍读取原 snapshot，安全审核未校验 body/下限。

- [✅] **Step 3: 最小实现**

高光只从 `_safe_material_refs()` 获得非敏感引用；模型 fallback 用无引用基础 Scene 补足到 3 个。扩展 `_is_safe_playback()`：Scene 数量为 3～16、`body` 缺失或长度不超过 80、无禁止表达、引用仍经过现有 allowlist。无效时 `_base_scenes_actions()` 返回 3 个无引用 `summary` Scene 和对应 `show_card` Action，不复制模型或素材正文。

- [✅] **Step 4: 运行绿灯与模型回归**

Run: `poetry run pytest -q tests/test_memoir_snapshot_runner.py tests/test_memoir_model_gateway.py`

Expected: PASS，脏模型输出与敏感引用只触发安全模板 fallback。
