# Task 9 回忆录内容安全与质量设计说明

> **2026-08-31 当前规则校准：** 本文最初对应 `memoir_agent@1.0.0` 的
> 3～8 Scene、80 字、媒体关闭 MVP。该历史合同只适用于
> `1.0.0`～`1.0.3`；`1.0.4` 已改为至少 3 个 Scene、场景数和正文长度
> 不设产品上限，并支持每场景配图。后续 `1.0.5` 的五类覆盖与动态生成仍是
> **待实现设计**，权威说明见
> [通用受控循环与 Memoir 动态生成设计说明](./2026-08-31-通用受控循环与Memoir动态生成设计说明.md)。

## 目标

让 MemoirAgent 在发布前先生成可追溯但无正文泄漏的语义脱敏素材，并稳定产出符合对应 AgentPackage 版本、情绪安全和媒体契约的播放文档。

## 已确认的脱敏策略

采用“保留引用、最小语义脱敏、敏感素材降权”：

- 每个素材保留稳定 `source_ref`、类型和最小统计信息，供后续引用校验与回忆链路追溯。
- 五类素材统一为 `diary/completed_bet/handbook_note/matured_wish/bucket_list_completion`；只有业务端提供安全 `text_digest` 的条目才允许以长度受限的摘要进入模型。昵称替换为“我/TA”，手机号、证件号、邮箱、地址、openid、token 和 URL 签名不进入 `sanitized_material`。
- 明确标记敏感的素材不传文本，只留下 `source_ref`、类型和 `sensitive=true`；高光、章节、场景只可降权或跳过该引用。
- 业务后端返回的未过滤敏感标识视为安全失败：只写标准错误码和计数，不保存触发内容，不调用模型。

## 工作流与状态

`1.0.0`～`1.0.4` 的静态节点主顺序为：

`load_snapshot -> sanitize_materials -> compute_stats -> extract_highlights -> plan_chapters -> generate_scenes -> generate_actions -> enqueue_media_tasks -> safety_review -> publish_document`

`AgentState.sanitized_material` 是唯一供高光/章节/场景模型节点读取的语义素材视图。原始 `snapshot` 只供 `sanitize_materials` 和计数型统计使用；日志、Artifact 和 checkpoint 摘要继续不展开两个字段的正文。

## 内容与发布约束

- `1.0.0`～`1.0.3` 冻结为 3～8 个 Scene、单 Scene `body` 最多 80 字；旧 Run 恢复必须继续按其 Package 执行，不能就地放宽。
- `1.0.4` 只保留至少 3 个 Scene，不设场景数与 `body` 产品上限；当前代码不存在“超过 16 张整批回退”的限制。
- `1.0.4` 媒体开启时按每个 Scene 的 `body` 逐场景尝试文生图，不设图片张数配额；单图失败、媒体预算耗尽或媒体关闭时对应 Scene 降级文字卡。`media_manifest` 始终必填，纯文字作品提交空数组。
- `1.0.4` 虽放开 Scene 数，但前置链仍最多选择 8 个 source ref、最多 3 章，且单次模型调用受上下文和输出 token 预算约束；因此它尚未实现五类素材充分展开。
- `1.0.5` 目标通过静态 DAG 内 `bounded_loop` 分批扫描五类合格素材，Scene 数由模型、素材量与技术预算共同决定；每个实际存在类型最终至少一个 Scene 必须携带该类型真实 source_ref。Business 必须提供安全 digest，缺失时 Runtime 契约 fail closed。该能力当前尚未实现。
- 禁止“关系失败、责备、复合暗示”等情绪风险表达；发现后回退基础安全卡，而不是把原始文案写入错误或审计。

## 非目标

- 不保存或分享五类素材完整正文，不接入 TTS 或视频生成；当前图片链只使用 Scene `body` 文生图，不读取 Snapshot 用户照片。
- 不修改业务后端 Snapshot 权限过滤；`bounded_loop` 不是动态工作流或动态工具选择，循环体不得含 Business Tool、上传或发布副作用。
- 不以 Runtime 日志、Artifact 或公开 callback 替代业务后端的完整作品存储。

## 验收

- 脱敏节点拒绝未过滤敏感标识，日志不回显正文；敏感素材不进入模型文本通道。
- 历史包继续通过 3～8/80 字冻结回归；`1.0.4` 的多于 8/16 Scene 与长正文不得被旧规则误杀。
- 待实现 `1.0.5` 覆盖空素材、单类型、五类齐全、大量素材、预算耗尽 partial、缺摘要 fail closed、缺类带真实引用修复和循环节点起点全量重算。
- 最终发布文档始终包含合法 Scene/Action 与必填 `media_manifest`；所有 Artifact/checkpoint 安全摘要无素材正文、prompt、模型候选或完整播放文档。
