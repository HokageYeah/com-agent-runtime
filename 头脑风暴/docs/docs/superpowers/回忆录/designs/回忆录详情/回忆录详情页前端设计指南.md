## 二、页面角色与设计目标

### 2.1 页面角色

回忆录详情页是单段回忆的沉浸式回看页面。它不承担日记详情、赌局详情或内容管理职责。

### 2.2 设计目标

- 让用户像看年度账单一样浏览一段关系的高光片段
- 用卡片、进度条和滑动切换形成明确叙事节奏
- 用温柔克制的文案表达“认真记录过”的价值
- 避免把页面做成数据报表或普通相册

---

## 三、页面信息架构

页面结构固定为：

1. 沉浸背景层
2. 顶部分段进度条
3. 标题与关闭按钮
4. 横向轮播容器
5. 闪回卡片
6. 左右切换控件
7. 底部滑动提示
8. 总结卡片

```text
进入详情页
  -> 加载闪回卡片集合
  -> 展示第一张封面卡
  -> 左右滑动切换卡片
  -> 进度条同步更新
  -> 最后一张展示总结卡
  -> 点击关闭返回列表
```

## 四、视觉设计规则

### 4.1 沉浸背景

- 背景使用 `#fff8f7` 为底。
- 可叠加柔和 radial gradient 或 mesh gradient。
- 可使用少量低透明心形粒子。
- 背景动效必须慢，不得分散用户对主卡片的注意力。

### 4.2 顶部控制区

- 顶部进度条使用分段形式。
- 当前进度使用品牌深粉，未完成部分使用低透明灰粉。
- 标题区左侧使用心形图标，文字为当前回忆名称。
- 关闭按钮使用圆形半透明玻璃按钮。

### 4.3 主卡片

- 主卡片居中展示。
- 移动端推荐宽度为屏幕宽度减去左右安全边距。
- 卡片比例建议为 `9:16`。
- 卡片圆角建议为 `32px`。
- 卡片阴影可以比列表页更强，但仍需保持粉调柔和。

### 4.4 卡片切换状态

- 当前卡片：清晰、不模糊、正常缩放。
- 非当前卡片：透明度降低、轻微缩小、可轻微模糊。
- 切换动画使用平滑位移和缩放，不使用翻页撕裂效果。

## 五、闪回卡片类型

### 5.1 封面卡

用于表达关系开始与回忆标题。

内容结构：

- 顶部或主体图片
- 柔和渐隐遮罩
- 起始日期标题
- 一句短文案

示例文案：

```text
我们从 2025年3月14日 开始记录
那一天的风很甜，像我们第一次在巷口相遇时的味道。
```

### 5.2 统计卡

用于表达关系持续时间、日记数量和关键词。

内容结构：

- 大数字
- 单位说明
- 日记数量卡片
- 关键词胶囊

### 5.3 精选瞬间卡

用于展示图片日记或重点日期。

内容结构：

- 卡片标题
- 精选图片
- 可选短说明
- 心形图标或精选角标

### 5.4 赌局高光卡

用于展示归档赌局中的趣味片段。

内容结构：

- 赌局标题
- 胜负或结果摘要
- 奖励内容
- 兑现状态

### 5.5 总结卡

用于温柔收尾。

内容结构：

- 强情绪标题
- 简短总结文案
- 低频操作按钮

总结卡文案必须克制，避免评价关系成败。

## 六、交互规则

### 6.1 滑动切换

- 移动端以左右滑动为主。
- 桌面或平板可展示左右箭头。
- 切换后进度条立即更新。
- 滑动提示只在底部低权重展示，不遮挡主卡。

### 6.2 返回列表

- 点击关闭按钮返回回忆录列表页。
- 返回时保留列表滚动位置和当前解锁状态。

### 6.3 保存与分享

- 总结卡可展示 `保存此回忆`。
- `分享给 TA` 只能作为低权重动作。
- 当前 MVP 若未实现保存或分享，可以作为占位按钮，但不能影响浏览主流程。

### 6.4 卡片数据加载

- 前端只展示服务端返回的闪回卡片集合。
- 若返回空数组，前端展示基础封面卡和空态总结卡。
- 若图片加载失败，保留文字内容和柔和占位图。

## 七、文案规则

### 7.1 文案气质

文案需要温柔、克制、轻仪式感。

可以使用：

- `谢谢你们认真记录过这一段时光`
- `这一段回忆，是我们共同写下的诗`
- `那些细小的瞬间，都被好好保存了`

避免使用：

- 评价关系失败或遗憾的文案
- 过度煽情的失恋文案
- 强行复合、强社交分享类文案

### 7.2 数据表达

- 大数字适合用于持续天数、日记数量、完成赌约数量。
- 关键词使用胶囊标签。
- 单张卡片的数据点不宜超过 3 个。

## 八、组件级实现约束

### 8.1 FlashbackCarousel

- 接收卡片数组和当前索引。
- 负责横向滚动、索引更新和进度同步。
- 不负责生成卡片内容。

### 8.2 FlashbackCard

- 根据卡片类型渲染不同内容结构。
- 保持统一圆角、阴影、字体和边距。
- 图片区域需要有加载失败兜底。

### 8.3 ProgressSegments

- 分段数量与卡片数量一致。
- 已浏览段填满。
- 当前段高亮。

### 8.4 AmbientBackground

- 只负责背景渐变和轻粒子。
- 动效不能影响页面性能。
- 低端设备可以关闭粒子动画。

---

## 九、给 LLM 的页面还原要求

LLM 生成详情页时不得遗漏：

- 沉浸背景
- 顶部分段进度条
- 标题与关闭按钮
- 横向闪回轮播
- 当前卡片与非当前卡片状态差异
- 封面卡、统计卡、精选瞬间卡、总结卡
- 底部滑动提示
- 空卡片兜底

落地后需要额外检查：

- 移动端主卡片是否完整可见。
- 进度条和关闭按钮是否不遮挡内容。
- 图片卡文字是否可读。
- 总结卡按钮是否不是页面唯一出口。
- 卡片切换是否平滑，没有明显卡顿。
