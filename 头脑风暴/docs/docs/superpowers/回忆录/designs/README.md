# 回忆录模块设计目录

本目录用于存放“回忆录”模块的页面原型、交互稿、视觉氛围和隐私提示方案。

编写要求：

- 开始模块设计前，先遵守 [整体设计/前端UI设计规范与AI提示词指南](../../整体设计/前端UI设计规范与AI提示词指南.md)
- 重点覆盖密码门禁、回忆录列表、详情浏览和空状态
- 设计上兼顾温度感与边界感，避免过度娱乐化
- 隐私提示和错误反馈需要简洁明确

专项设计入口：

- 回忆录模块整体设计：[回忆录模块前端设计指南](./回忆录模块前端设计指南.md)
- 回忆录列表页专项设计：[回忆录列表/回忆录列表页前端设计指南](./回忆录列表/回忆录列表页前端设计指南.md)
- 回忆录详情页专项设计：[回忆录详情/回忆录详情页前端设计指南](./回忆录详情/回忆录详情页前端设计指南.md)
