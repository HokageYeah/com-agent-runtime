# “赌局页”设计目录

本目录用于存放“赌局页”在未登录、已登录未绑定、已登录已绑定，以及已登录发起赌约页面下的前端设计说明、页面还原依据、状态样式规则和代码参考索引。

阅读顺序建议：

1. 先阅读 [赌局页前端设计指南](./赌局页前端设计指南.md)
2. 再查看全局设计基线 [整体设计/前端UI设计规范与AI提示词指南](../../../整体设计/前端UI设计规范与AI提示词指南.md)
3. 再查看打赌系统 [需求设计文档](../../需求设计文档.md)
4. 最后参考本目录下的代码样例进行页面还原

代码参考位置：

- 未登录态页面代码：[`code/未登录/code.html`](./code/未登录/code.html)
- 已登录未绑定页面代码：[`code/已登录未绑定/code.html`](./code/已登录未绑定/code.html)
- 已登录已绑定页面代码：[`code/已登录已绑定/code.html`](./code/已登录已绑定/code.html)
- 已登录发起赌约页面代码：[`code/已登录发起赌约/code.html`](./code/已登录发起赌约/code.html)
- 风格母版设计系统：[`code/lover_s_journal/DESIGN.md`](./code/lover_s_journal/DESIGN.md)

页面状态：

- 未登录态：展示趣味赌局 Hero、登录 / 注册 CTA、锁定时间线预览、锁定战绩卡片
- 已登录未绑定：展示已登录头像 / 身份感、绑定另一半 CTA、锁定时间线预览，不展示真实赌局和发起能力
- 已登录已绑定：展示中轴赌局时间线、赌局状态卡片、待兑现提醒、战绩统计和发起赌局入口
- 已登录发起赌约：展示发起新赌约表单、奖励快捷选项、截止时间选择、挑战关系确认和底部固定发布按钮

使用规则：

- 后续让 LLM 还原“赌局页”时，必须同时参考本目录设计指南、全局设计规范、需求设计文档和对应状态的参考代码。
- 如果后续新增“空数据态”“异常加载态”等状态页面，也应优先在本目录下扩展。
- 发起赌注页、赌注详情页如果单独设计，应继续继承本指南中的赌局状态、文案语气和视觉层级。
