# 打赌系统前端 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `frontend/couple-diary-f` 中按全局暖粉情侣日记设计系统落地打赌系统页面，包括赌局页三态、发起赌注页、赌注详情页、状态交互、API 封装和联调验证。

**Architecture:** 前端新增 `pages-bets` 业务分包，主包 `pages/bets/bets.vue` 只做 Tab 冷启动跳板，真实页面收口到 `src/uni_modules/pages-bets`。业务状态通过 `use-bet-page.ts`、`use-bet-create.ts`、`use-bet-detail.ts` 管理，接口契约收口到 `uni-module-common/types/couple-bet.ts` 与 `uni-module-common/bets/couple-bet-api.ts`，页面视觉严格参考赌局页设计指南和四份状态 code.html。

**Tech Stack:** UniApp、Vue 3 `<script setup>`、TypeScript、Pinia、`request<T>()` 请求封装、ThorUI / XXT easycom、SCSS。

## 1. 成功标准

- TabBar 第二页为“赌约 / 赌局”，进入后展示打赌系统。
- 未登录态保持设计不变：趣味 Hero、登录 / 注册 CTA、锁定时间线预览、锁定战绩区。
- 已登录未绑定态展示头像、待邀请另一半占位、立即绑定 CTA、锁定时间线预览，不展示真实赌局、真实战绩或 FAB。
- 已登录已绑定态展示中轴时间线、日期分组、左 TA / 右我、状态卡片、待兑现呼吸提醒、战绩统计和发起赌局 FAB。
- 已登录已绑定态点击发起赌局 FAB 后进入发起赌约页；未登录或未绑定用户不能进入真实发起页。
- 发起赌注页按 `已登录发起赌约/code.html` 还原顶部关闭导航、发起 Header、表单卡片、奖励快捷选项、截止时间选择、挑战关系确认和底部固定发布按钮。
- 发起赌注页支持填写标题、判定条件、奖励、截止时间，提交前调用奖励敏感词检查，命中时展示温和确认，发布成功后返回赌局页刷新。
- 赌注详情页支持 pending 回应、settling 提交/确认结果、redeeming 标记兑现/确认收到、协商消息展示与发送。
- 赌注详情页按 `已登录赌局详情页/code.html` 重构：Hero 状态卡、截止倒计时、奖励信息、双方参与人、手动截止三选一和底部提交按钮。
- `active` 赌局详情页支持手动截止，用户必须选择“我赢了 / TA 赢了 / 平局不算”之一后才能提交。
- 手动截止选择“我赢了 / TA 赢了”后进入待结算确认；选择“平局不算”后进入历史作废态，不展示兑现入口。
- 自然到期的 `active` 赌局详情页必须停止倒计时，并展示胜负判定操作；不能卡在无操作的详情页。
- 自然到期后的待结算操作必须支持“我赢了 / TA 赢了 / 平局不算”。
- 赌局首页在页面可见期间需要刷新真实时间线，避免用户停留页面时到期赌局仍显示“进行中”。
- `redeeming/completed` 状态在时间线卡片和详情页展示赢家文案，例如“我赢了”或“TA 赢了”。
- 用户解绑后再次进入赌局页，应回到已登录未绑定态，不展示原情侣关系下的真实赌局、真实战绩、发起 FAB 或详情操作入口；历史赌局展示由回忆录模块承接。
- 所有页面主背景、文本、圆角、阴影、字号、动效符合全局设计规范，不使用脚手架绿色/蓝色主视觉。
- 新增或修改的类型、状态、关键流程包含中文注释和可搜索日志。
- 执行 `npm run type-check`，并至少执行 `npm run build:mp-weixin` 或说明未执行原因。

- `POST /bets/reward-check`
- `POST /bets`
- `GET /bets/timeline`
- `GET /bets/stats`
- `GET /bets/{betId}`
- `POST /bets/{betId}/respond`
- `POST /bets/{betId}/manual-close`

```ts
export type BetStatus =
  | 'pending'
  | 'rejected'
  | 'active'
  | 'settling'
  | 'redeeming'
  | 'completed'
  | 'expired';

export type BetSide = 'partner' | 'self';
export type BetRespondAction = 'accept' | 'reject';
export type SettlementAction = 'propose' | 'draw' | 'agree' | 'disagree';

export interface RewardCheckRequest {
  /** 奖励内容，用于后端敏感词温和提醒，不用于强制拦截。 */
  reward: string;
}

export interface RewardCheckData {
  /** 是否命中奖励敏感词。 */
  hit: boolean;
  /** 展示给用户的温和提示文案。 */
  message: string;
  /** 命中的敏感词列表，仅用于提示和调试，不做强警告展示。 */
  words: string[];
}

export interface CreateBetRequest {
  /** 赌什么，展示在赌局卡片主标题。 */
  title: string;
  /** 赢的判定规则，详情页用于说明如何结算。 */
  winCondition: string;
  /** 输方需要兑现的奖励。 */
  reward: string;
  /** 截止时间 ISO 字符串。 */
  deadlineAt: string;
}

export interface BetCardData {
  /** 赌局 ID，用于进入详情页。 */
  id: number;
  /** 当前用户视角下的中轴线归属，partner 在左侧，self 在右侧。 */
  side: BetSide;
  /** 发起方展示文案，只允许 TA 发起或我发起。 */
  initiatorLabel: string;
  /** 后端状态机状态。 */
  status: BetStatus;
  /** 状态展示文案，例如进行中、待结算、待兑现。 */
  statusText: string;
  /** 赌局标题。 */
  title: string;
  /** 奖励内容。 */
  reward: string;
  /** 截止时间 ISO 字符串。 */
  deadlineAt: string;
  /** 结果或兑现补充文案。 */
  resultText?: string | null;
  /** 是否启用待兑现呼吸提醒。 */
  highlight: boolean;
}

export interface BetTimelineGroup {
  /** 日期分组，格式示例 2026-06-23。 */
  date: string;
  /** 页面展示日期，例如 今天 / 2026年6月10日。 */
  displayDate: string;
  /** 当前日期下的赌局卡片。 */
  items: BetCardData[];
}

export interface BetStatsData {
  /** 另一半胜场。 */
  partnerWins: number;
  /** 我的胜场。 */
  selfWins: number;
  /** 履约率百分比。 */
  fulfillmentRate: number;
  /** 最常出现的奖励。 */
  topReward: string;
}
```

- [ ✅ ] **Step 2: 写 API 文件**

```ts
import { request } from '@/uni-module-common/http';
import type { ApiResponse } from '@/uni-module-common/http';
import type {
  BetCardData,
  BetStatsData,
  BetTimelineGroup,
  CreateBetRequest,
  RewardCheckData,
  RewardCheckRequest
} from '@/uni-module-common/types/couple-bet';

export function checkRewardApi(data: RewardCheckRequest): Promise<ApiResponse<RewardCheckData>> {
  return request<RewardCheckData>({
    url: '/bets/reward-check',
    method: 'POST',
    data,
    custom: { auth: true, showLoading: false }
  });
}

export function createBetApi(data: CreateBetRequest): Promise<ApiResponse<BetCardData>> {
  return request<BetCardData>({
    url: '/bets',
    method: 'POST',
    data,
    custom: { auth: true, showLoading: true }
  });
}

export function getBetTimelineApi(): Promise<ApiResponse<BetTimelineGroup[]>> {
  return request<BetTimelineGroup[]>({
    url: '/bets/timeline',
    method: 'GET',
    custom: { auth: true, showLoading: false }
  });
}

export function getBetStatsApi(): Promise<ApiResponse<BetStatsData>> {
  return request<BetStatsData>({
    url: '/bets/stats',
    method: 'GET',
    custom: { auth: true, showLoading: false }
  });
}
```
