# 登录与绑定前端 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `frontend/couple-diary-f` 中按登录与绑定设计稿落地微信登录、角色选择、邀请码绑定、我的页三态展示与正式登录闭环。

**Architecture:** 前端沿用 UniApp + Vue 3 + TypeScript + Pinia 的现有脚手架，把真实登录能力收口到 `uni-module-public/login`、`uni-module-common/store/user.ts`、业务 API hook 和 `pages-mine`。页面视觉严格继承暖粉色设计系统，登录成功但未绑定时继续留在绑定流程，只有绑定成功才返回来源页。

**Tech Stack:** UniApp、Vue 3 `<script setup>`、TypeScript、Pinia、`uni-ajax` 请求封装、ThorUI / XXT easycom、SCSS。

## 1. 成功标准

- 用户从任意来源页进入登录流程时，来源页被记录。
- 登录页要求先选择角色、勾选协议，再调用微信登录。
- `wx.login` 成功后调用后端登录接口，写入 token、用户资料、角色标签和关系状态。
- 如果后端返回 `relationship.status !== "BOUND"`，前端进入邀请与绑定页。
- 邀请与绑定页展示我的邀请码，支持复制、输入绑定码、扫码入口占位和绑定成功回跳。
- 绑定成功后才视为正式登录完成，并返回来源页刷新已登录态。
- 我的页支持未登录、已登录未绑定、已绑定三种前端状态。
- 我的页登录后支持昵称编辑弹窗，昵称最多 5 个字，保存后立即刷新本地用户态。
- UI 主色、背景、圆角、阴影、动效符合全局设计规范，不再使用当前脚手架绿色/蓝色视觉。
- 新增/修改核心逻辑包含中文注释和关键日志。
- 执行 `npm run type-check`，并至少执行 `npm run build:mp-weixin` 或说明未执行原因。

## 3. API 契约

前端按以下响应读取 `data`。外层仍使用后端统一响应：

```ts
export type CoupleRoleTag = 'HE' | 'SHE';
export type RelationshipStatus = 'UNBOUND' | 'INVITING' | 'BOUND' | 'UNBIND_REQUESTED' | 'UNBOUND_ARCHIVED' | 'BLOCK_COOLDOWN';

export interface CoupleUserInfo {
  id: string | number;
  nickname: string;
  avatar: string;
  roleTag: CoupleRoleTag;
}

export interface CoupleRelationshipInfo {
  status: RelationshipStatus;
  coupleId?: string | number;
  boundAt?: string;
  partner?: CoupleUserInfo | null;
}

export interface LoginByWechatData {
  token: string;
  user: CoupleUserInfo;
  relationship: CoupleRelationshipInfo;
}

export interface BindingInviteData {
  bindingCode: string;
  expiresAt: string;
}
```

接口列表：

- `PATCH /api/v1/auth/me/profile`
  - 入参：`{ nickname: string }`，trim 后 1-5 个字
  - 出参：`CoupleUserInfo`
- `POST /api/v1/auth/wechat-login`
  - 入参：`{ code: string; roleTag: 'HE' | 'SHE'; nickname?: string; avatar?: string }`
  - 出参：`LoginByWechatData`
- `GET /api/v1/relationship/me`
  - 出参：`CoupleRelationshipInfo`
- `POST /api/v1/relationship/invites`
  - 出参：`BindingInviteData`
- `GET /api/v1/relationship/invites/{bindingCode}`
  - 出参：`{ inviter: CoupleUserInfo; expiresAt: string }`
- `POST /api/v1/relationship/bind`
  - 入参：`{ bindingCode: string }`
  - 出参：`CoupleRelationshipInfo`

  status: RelationshipStatus;

  coupleId?: string | number;
  /** 绑定成功时间，用于我的页关系天数展示。 */

  /** 微信昵称，接口允许缺省。 */
  nickname?: string;
  /** 微信头像，接口允许缺省。 */
  avatar?: string;
}

export interface LoginByWechatData {
  /** 后端签发的会话 token，后续请求放入公共请求层。 */
  token: string;
  /** 当前登录用户资料。 */
  user: CoupleUserInfo;
  /** 当前用户关系状态。 */
  relationship: CoupleRelationshipInfo;
}

export interface BindingInviteData {
  /** 当前用户生成的邀请码。 */
  bindingCode: string;
  /** 邀请码过期时间。 */
  expiresAt: string;
}

- [ ✅ ] **Step 2: 写 API 文件**

```ts
import { request } from '@/uni-module-common/http';
import type { ApiResponse } from '@/uni-module-common/http';
import type {
  BindingInviteData,
  CoupleRelationshipInfo,
  LoginByWechatData,
  LoginByWechatRequest
} from '@/uni-module-common/types/couple-auth';

export function loginByWechatApi(data: LoginByWechatRequest): Promise<ApiResponse<LoginByWechatData>> {
  return request<LoginByWechatData>({
    url: '/auth/wechat-login',
    method: 'POST',
    data,
    custom: { auth: false, showLoading: false }
  });
}

export function getMyRelationshipApi(): Promise<ApiResponse<CoupleRelationshipInfo>> {
  return request<CoupleRelationshipInfo>({
    url: '/relationship/me',
    method: 'GET',
    custom: { auth: true, showLoading: false }
  });
}

export function createBindingInviteApi(): Promise<ApiResponse<BindingInviteData>> {
  return request<BindingInviteData>({
    url: '/relationship/invites',
    method: 'POST',
    custom: { auth: true, showLoading: false }
  });
}

export function bindByCodeApi(bindingCode: string): Promise<ApiResponse<CoupleRelationshipInfo>> {
  return request<CoupleRelationshipInfo>({
    url: '/relationship/bind',
    method: 'POST',
    data: { bindingCode },
    custom: { auth: true, showLoading: false }
  });
}
```
