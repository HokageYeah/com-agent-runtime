# 登录与绑定模块设计目录

本目录用于存放“登录与绑定”模块的产品设计、交互稿、页面结构图和视觉说明。

编写要求：

- 开始模块设计前，先遵守 [整体设计/前端UI设计规范与AI提示词指南](../../整体设计/前端UI设计规范与AI提示词指南.md)
- 设计稿需围绕登录、角色选择、绑定、解绑、拉黑等页面展开
- 所有设计说明使用统一术语，和需求文档保持一致
- 设计稿中的流程图和状态说明应能直接映射到需求文档
