# “我的”模块设计目录

本目录用于存放“我的”页面在未登录、登录未绑定、登录已绑定三种状态下的前端设计说明、页面还原依据和代码参考索引。

阅读顺序建议：

1. 先阅读 [我的模块前端设计指南](./我的模块前端设计指南.md)
2. 再查看全局设计基线 [整体设计/前端UI设计规范与AI提示词指南](../../../整体设计/前端UI设计规范与AI提示词指南.md)
3. 最后参考本目录下的代码样例进行页面还原

代码参考位置：

- 未登录态页面代码：[`code/未登录/code.html`](./code/未登录/code.html)
- 登录未绑定页面代码：[`code/登录未绑定/code.html`](./code/登录未绑定/code.html)
- 登录已绑定页面代码：[`code/登录已绑定/code.html`](./code/登录已绑定/code.html)
- 登录绑定后关系设置页面代码：[`code/登录绑定后关系设置/code.html`](./code/登录绑定后关系设置/code.html)
- 登录绑定后关系设置设计系统：[`code/登录绑定后关系设置/DESIGN.md`](./code/登录绑定后关系设置/DESIGN.md)
- 风格母版设计系统：[`code/lover_s_journal/DESIGN.md`](./code/lover_s_journal/DESIGN.md)

使用规则：

- 后续让 LLM 还原“我的”页面时，必须同时参考本目录设计指南、全局设计规范和对应状态的参考代码。
- 不允许再把“登录态”合并成单一页面：登录后必须继续按 `relationshipStatus === "BOUND"` 区分“登录未绑定”和“登录已绑定”。
- 如果后续新增“我的”页面下的子页面设计，也应优先继承本指南中定义的页面结构和组件语义。
