# 整体设计目录

本目录用于存放《情侣日记》小程序的全局前端 UI 设计基线，包括主题色、设计理念、组件规范、动效约束和 AI 出图 / 出码提示词规则。

使用规则：

- 所有模块级页面设计都必须以本目录中的全局设计规范为基础。
- 模块自己的设计文档只补充该模块的页面结构、状态样式、交互细节和业务特化说明。
- 如果模块设计与全局规范发生冲突，优先回到本目录修订全局规范，而不是在模块文档中单独覆盖。
- 后续新增全局导航、卡片系统、按钮系统、字体策略、动效策略时，也统一沉淀在本目录。
