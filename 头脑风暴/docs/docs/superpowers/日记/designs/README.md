# 日记模块设计目录

本目录用于存放“日记”模块的页面原型、交互稿、视觉规范和内容展示方案。

编写要求：

- 开始模块设计前，先遵守 [整体设计/前端UI设计规范与AI提示词指南](../../整体设计/前端UI设计规范与AI提示词指南.md)
- 重点覆盖首页时间线、日历模式、写日记、详情页
- 说明图片展示、空状态、加载状态和删除申请反馈
- 保持温暖轻松的产品语气和视觉方向

专项设计入口：

- “日记页”专项设计：[日记页/日记页前端设计指南](./日记页/日记页前端设计指南.md)

阅读顺序建议：

1. 先阅读 [需求设计文档](../需求设计文档.md)，理解日记发布、时间线浏览、日历模式和删除申请流程
2. 再阅读 [整体设计/前端UI设计规范与AI提示词指南](../../整体设计/前端UI设计规范与AI提示词指南.md)
3. 再阅读 [日记页/日记页前端设计指南](./日记页/日记页前端设计指南.md)
4. 最后查看日记页代码参考，按登录态或未登录态分别还原页面

设计输出约束：

- 日记页必须继承产品全局中轴时间线规则：左侧为 `TA / 对方`，右侧为 `我 / 自己`
- 未登录态不能展示真实共享日记，只展示情感引导、登录入口和预览内容
- 已登录态必须清楚表达日期分组、作者归属、发布时间、正文和图片状态
- 日历模式与时间线模式必须使用同一份日记数据源，不允许产生展示口径差异
