# “日记页”设计目录

本目录用于存放“日记页”在登录态与未登录态下的前端设计说明、页面还原依据、时间线规则、日历模式规则和代码参考索引。

阅读顺序建议：

1. 先阅读 [日记页前端设计指南](./日记页前端设计指南.md)
2. 再查看全局设计基线 [整体设计/前端UI设计规范与AI提示词指南](../../../整体设计/前端UI设计规范与AI提示词指南.md)
3. 再查看日记模块 [需求设计文档](../../需求设计文档.md)
4. 最后参考本目录下的代码样例进行页面还原

代码参考位置：

- 已登录态页面代码：[`code/已登录/code.html`](./code/已登录/code.html)
- 未登录态页面代码：[`code/未登录/code.html`](./code/未登录/code.html)
- 风格母版设计系统：[`code/lover_s_journal/DESIGN.md`](./code/lover_s_journal/DESIGN.md)

页面状态：

- 未登录态：展示情感插画 Hero、登录 / 注册 CTA、共享日记预览时间线和底部导航
- 已登录态：展示中轴日记时间线、日期分组、日记卡片、图片网格、日历入口和写日记 FAB

使用规则：

- 后续让 LLM 还原“日记页”时，必须同时参考本目录设计指南、全局设计规范、需求设计文档和对应状态的参考代码。
- 如果后续新增“空数据态”“已登录未绑定态”“日历展开态”“加载失败态”等状态页面，也应优先在本目录下扩展。
- 写日记页、日记详情页如果单独设计，应继续继承本指南中的作者归属、图片展示、删除申请和文案语气规则。
