## 2. P1 级打磨建议（非阻塞，建议开发前/中完善）

| 序号 | 建议点 | 详细说明 | 优先级 |
| :--- | :--- | :--- | :--- |
| 1 | **Callback 签名验证** | 目前 Runtime 到业务的调用有签名，但业务到 Runtime 的 Callback 缺失。建议复用既有算法（HMAC-SHA256），防止伪造回调。 | **最高** |
| 2 | **对账任务参数定义** | 补充 Cron Job 的调度频率（如 5min/次）、连续失败阈值及升级告警机制，避免运维侧实现标准不一。 | 高 |
| 3 | **重试计数器隔离** | 明确“用户手动重试”与“Runtime 自动重试”是两套独立的计数器，互不消耗配额。 | 中 |
| 4 | **幂等补偿逻辑** | 明确补偿重试时必须强制复用原始 `Idempotency-Key`，否则幂等保护将失效。 | 中 |
| 5 | **隐私告警处理动作** | 明确“业务侧已过滤字段重新出现”时的处置动作（建议：立即阻断 Run 并转入 Human Review/Failed）。 | 中 |
| 6 | **幂等冲突响应格式** | 统一返回 `409 Conflict` 状态码，并复用已定义的错误码结构（增加 `IDEMPOTENCY_CONFLICT`）。 | 低 |
